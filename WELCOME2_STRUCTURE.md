## 📏 Dimensions et Espacements

### Sections
- **Padding vertical**: 100px (Desktop), 60px (Mobile)
- **Margin bottom**: 60px pour les titres de section

### Cartes
- **Padding**: 40px 30px (Desktop), 30px 20px (Mobile)
- **Border-radius**: 10px
- **Box-shadow**: 0 5px 20px rgba(0,0,0,0.08)
- **Hover shadow**: 0 15px 40px rgba(0,123,255,0.2)

### Images
- **Carrousel**: 1920x700px
- **Structures**: 100% width, 280px height
- **Témoignages (avatar)**: 60x60px (cercle)

### Typographie
- **Titre H2**: 40px (Desktop), 32px (Tablet), 28px (Mobile)
- **Titre H3**: 22px (Services), 20px (Structures), 18px (Témoignages)
- **Texte**: 16px (Principal), 15px (Secondaire), 14px (Petit)
- **Line-height**: 1.6 - 1.8

## 🎭 Animations

### WOW.js
```
fadeInLeft   - Image "Qui sommes-nous"
fadeInRight  - Contenu "Qui sommes-nous"
fadeInUp     - Cartes de services, structures, témoignages
```

### Délais
```
0ms    - Premier élément
300ms  - Deuxième élément
600ms  - Troisième élément
```

### Transitions CSS
```
all 0.3s ease  - Effets hover généraux
transform 0.5s - Zoom images
opacity 0.3s   - Overlays
```

## 📱 Breakpoints Responsive
